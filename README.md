# depot.social

![Logo](./favicon.png)

**Resource booking platform for cities, regions and neighbourhoods.**

This monorepo uses [pnpm workspaces](https://pnpm.io/workspaces). Packages:

| Package name | Path | Description |
| - | - | - |
| `@depot/strapi` | [packages/strapi](./packages/strapi/README.md) | Strapi v5 application: data schemas, admin UI, API, core policies/services |
| `@depot/nuxt` | [packages/nuxt](./packages/nuxt/README.md) | Nuxt 4 frontend using Nuxt UI, daisyUI, Leaflet, valibot |
| `@depot/shared` | [packages/shared](./packages/shared/README.md) | Shared utilities, requests and TypeScript definitions |
| `@depot/availabilities` | [packages/strapi/src/plugins/availabilities](./packages/strapi/src/plugins/availabilities/README.md) | Strapi plugin: availability logic & API |
| `@depot/conversations` | [packages/strapi/src/plugins/conversations](./packages/strapi/src/plugins/conversations/README.md) | Strapi plugin: socket.io realtime chat |
| `@depot/prices` | [packages/strapi/src/plugins/prices](./packages/strapi/src/plugins/prices/README.md) | Strapi plugin: price calculation |
| `@depot/import-csv` | [packages/strapi/src/plugins/import-csv](./packages/strapi/src/plugins/import-csv/README.md) | Strapi plugin: import resources/bookings/units/users from CSV |
| `@depot/emails` | [packages/strapi/src/plugins/emails](./packages/strapi/src/plugins/emails/README.md) | Strapi plugin: email sending (e.g. booking confirmations) |
| `@depot/rental-agreement` | [packages/strapi/src/plugins/rental-agreement](./packages/strapi/src/plugins/rental-agreement/README.md) | Strapi plugin: PDF rental agreement generation |

Planned (WIP): `@depot/notifications`, `@depot/resource-type-units`.

## Features

- **REST & GraphQL API**, OpenAPI documentation and JWT-based user authentication
- **Extendable & customizable** thanks to [Strapi CMS](https://strapi.io/)
- **Performant, secure, accessible**
- **Easy deployment** via e.g. Netlify, Vercel, AWS, Strapi cloud
- **Responsive images** ([strapi-plugin-image-sharp](https://github.com/strapi-community/strapi-plugin-local-image-sharp))
- **Covered by (unit) tests** with [Vitest](https://vitest.dev/)
- **Privacy friendly**: GDPR compatible; obfuscated addresses

## Requirements

- [Node](https://nodejs.org/en/download/) >=20
- [pnpm](https://pnpm.io/)

Optional for maps/geolocation: a Mapbox account/API token.

## Quick start

1) Install dependencies
```
pnpm install
```

2) Copy `.env` from `.env.example` in the repository root and set required values.


3) Development
- Start backend and frontend in parallel:
```
pnpm dev
```
  - Strapi: http://127.0.0.1:1337 (admin at /admin)
  - Nuxt:   http://127.0.0.1:3000

Alternatively in separate terminals:
```
pnpm --filter @depot/strapi dev
pnpm --filter @depot/nuxt dev
```

4) Production
```
pnpm build
# Then run
pnpm -C packages/strapi start
pnpm -C packages/nuxt preview
```

## pnpm workspace usage

- Run a script inside a specific package:
```
pnpm --filter @depot/shared develop
```

- Add a local dependency to another package:
```
pnpm --filter @depot/nuxt add @depot/shared
```

## Plugins: enable/disable

All shipped Strapi plugins are enabled by default except `@depot/import-csv`.
Disable any plugin by setting its env to `false` in `.env`, e.g.:
```
STRAPI_PLUGIN_AVAILABILITIES=false
```

## OAuth integration

Strapi supports external auth providers. Add a provider per
[Users & Permissions docs](https://docs.strapi.io/dev-docs/plugins/users-permissions#setting-up-the-provider---examples)
and integrate on the frontend per
[nuxt-strapi auth docs](https://strapi.nuxtjs.org/auth#authenticateprovider).

## Tests and formatting

- Unit tests (Vitest): `pnpm test`
- Code formatting (Prettier): `pnpm prettier`

## API documentation

OpenAPI/Swagger JSON (generated by Strapi Documentation plugin) is available at:
`packages/strapi/src/extensions/documentation/documentation/<version>/full_documentation.json`.
You can also enable Swagger UI via the Strapi admin ("Documentation").
